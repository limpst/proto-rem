# proto-rem

리멤버(Remember) 명함 서비스에서 수집한 연락처 데이터를 기반으로,
각 연락처의 **회사 홈페이지를 읽어 맞춤 광고 메시지를 생성·발송**하는 프로토타입.

## 파이프라인

1. **수집** — 리멤버 명함 데이터에서 이름·회사·직함·연락처 추출
2. **조사** — 회사 홈페이지 크롤링 후 사업 영역·최근 소식 요약
3. **생성** — 회사별 컨텍스트를 반영한 광고/제안 메시지 작성
4. **발송** — 채널별 전송 및 발송 이력 기록

## 상태

초기 세팅 단계. 구현 예정.

## 유의사항

- 명함 데이터는 개인정보이므로 저장소에 원본 데이터를 커밋하지 않는다 (`.gitignore` 참고).
- 광고성 정보 전송은 정보통신망법상 **사전 수신동의**가 필요하다. 발송 단계에는 동의 여부 확인과 수신거부 처리가 포함되어야 한다.
