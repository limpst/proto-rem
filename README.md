# SafeLead

> 저장소 이름은 `proto-rem`, 제품 이름은 **SafeLead** 입니다.

㈜에이톰엔지니어링(국토교통부 지정 안전진단전문기관)의 **영업 메일 자동 작성 도구**입니다.

## 이게 뭘 하는 프로그램인가요?

한 문장으로: **명함첩에 잠자고 있는 연락처를, 보낼 만한 영업 메일로 바꿔 줍니다.**

지금까지는 이렇게 하셨을 겁니다.

> 리멤버에 명함이 3천 장 쌓여 있다 → 누구에게 연락할지 모르겠다 →
> 연락한다 해도 "안녕하세요, 저희는 안전진단 전문업체입니다" 같은 똑같은 메일만 보낸다 →
> 아무도 답장하지 않는다

이 프로그램은 이렇게 바꿉니다.

> 명함을 전부 가져온다 → 회사별로 종류를 나눈다(백화점/대학/철탑/시공사…) →
> **그 회사 홈페이지를 직접 읽는다** → "귀사 ○○점은 1998년 개점한 8층 건물이고
> 지하주차장이 3개 층인데, 이 정도면 정밀안전점검 주기가 도래하는 경우가 많습니다" 처럼
> **그 회사에만 해당하는 이야기**로 메일을 쓴다 → 사람이 읽어보고 승인한 것만 보낸다

핵심은 **"지금 연락할 이유"** 입니다. 건축물 안전관리는 법으로 점검 주기가 정해져 있어서,
"언제쯤 점검을 받아야 하는지"를 짚어주면 광고가 아니라 도움이 됩니다.

### 준비물

컴퓨터에 아래 것들이 있어야 합니다. 없으면 링크에서 받으세요.

| 이름 | 어디에 쓰나 | 확인 방법 | 없을 때 |
|---|---|---|---|
| **Python 3.12+** | 프로그램 본체(서버) | 터미널에 `python --version` | https://python.org 에서 설치 |
| Node.js | 리멤버 명함 수집(브라우저 자동화)에만 | `node -v` | https://nodejs.org 에서 LTS 설치 |
| AI 하나 | 메일 문구 작성 | 아래 셋 중 하나면 됩니다 | |

AI 는 셋 중 **하나만** 있으면 됩니다.

| 방법 | 속도 | 데이터가 나가는가 | 준비 |
|---|---|---|---|
| `claude-api` | 빠름 (한 통 10~15초) | 나감 (Anthropic) | `ANTHROPIC_API_KEY` |

| `ollama` | 느림 (한 통 1~3분) | **안 나감 (내 PC 안)** | Ollama 실행 + 모델 받기 |

> 서버에 올릴 때는 **반드시 `claude-api`** 로 두세요. 서버에는 Claude Code 도 Ollama 도 없습니다.

> **터미널이 뭔가요?** 윈도우 검색창에 `PowerShell`을 치면 나오는 검은 창입니다.
> 명령어를 한 줄씩 입력하는 곳입니다.

### 1단계 — 프로그램 받기

터미널에 아래를 한 줄씩 붙여넣고 Enter를 누르세요.

```powershell
git clone https://github.com/limpst/proto-rem
cd proto-rem
npm install
```

`npm install`은 필요한 부품을 내려받는 과정입니다. 1~2분 걸립니다.

### 2단계 — 실행하기

```powershell
npm start
```

이렇게 나오면 성공입니다.

```
proto-rem 대시보드 → http://localhost:5173
```

**이 터미널 창을 닫지 마세요.** 닫으면 프로그램이 꺼집니다.

### 3단계 — 화면 열기

크롬 주소창에 `localhost:5173` 을 입력하세요. 왼쪽에 1번부터 7번까지 메뉴가 보이면 성공입니다.

> **포트를 바꾸고 싶다면**: `$env:PORT=8787; npm start` 처럼 실행하면 `localhost:8787`로 열립니다.

## 화면 사용법 — 1번부터 7번까지

왼쪽 메뉴를 위에서 아래로 순서대로 누르시면 됩니다.
**`HUMAN` 이라고 표시된 3곳은 사람이 직접 결정해야 하는 자리**입니다. 나머지는 자동입니다.

### STEP 1. 명함 수집 — 리멤버에서 명함 가져오기

세 가지 방법이 있습니다. **② 콘솔 스니펫이 제일 쉽습니다.**

#### 방법 ② 콘솔 스니펫 (권장)

1. 크롬에서 `card.rememberapp.co.kr` 을 엽니다. (평소처럼 로그인된 상태 그대로)
2. 키보드 **F12** 를 누릅니다. 오른쪽에 개발자 창이 열립니다.
3. 위쪽 탭에서 **Console** 을 클릭합니다.
4. 아래 한 줄을 복사해서 붙여넣고 Enter:

   ```js
   fetch('http://localhost:5173/collect-snippet.js').then(r=>r.text()).then(eval)
   ```

   > 크롬이 "붙여넣기를 허용하지 않습니다" 라고 하면,
   > 콘솔에 `allow pasting` 이라고 직접 타이핑하고 Enter를 누른 뒤 다시 붙여넣으세요.

5. 화면 오른쪽 아래에 작은 상자가 뜹니다. **명함 목록을 마우스로 끝까지 스크롤**하세요.
   상자의 숫자가 올라갑니다.
6. 상자의 **[대시보드로 바로 보내기]** 를 누릅니다. 끝입니다.
7. 대시보드로 돌아와 **[명함 불러오기]** 를 누르면 명함이 표에 나타납니다.

#### 방법 ① 전용 브라우저 로그인

`[브라우저 열어 로그인]` 을 누르면 이 프로그램 전용 크롬 창이 열립니다.
거기서 **직접 로그인**하시면 저장되고, 다음부터는 `[전부 가져오기]` 버튼만 누르면 됩니다.

> 구글 로그인은 자동화된 창에서 차단됩니다. **네이버나 카카오로 로그인**하세요.

#### 방법 ③ CDP 접속

완전 자동이지만 크롬을 껐다 켜야 합니다.

```powershell
Get-Process chrome | Stop-Process -Force
& "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```

그다음 `[CDP 로 가져오기]`.

> **자사 명함은 자동으로 빠집니다.** 명함첩에는 에이톰 직원분들 명함도 섞여 있는데,
> 회사명이 에이톰이면 `자사 · 발송제외` 로 표시되고 체크박스 자체가 사라집니다.

---

### STEP 2. 발신·발송모드 `HUMAN`

세 가지를 정합니다.

**① 보내는 회사** — ㈜에이톰엔지니어링으로 고정입니다. 바꿀 수 없습니다.

**② 누구 이름으로 보낼까** — 고르는 사람에 따라 말투가 달라집니다.

| 고르면 | 이렇게 써집니다 |
|---|---|
| 대표 | 짧고 단정하게. "제가 직접 검토해 드리겠습니다" |
| 마케팅 담당자 | 친절하게. 무엇을 무료로 드리는지 자세히 |
| 영업 담당자 | 만난 이야기를 먼저 꺼내고 한 가지만 제안 |
| 기술 담당자 | 기술적인 근거 위주 |

**③ 1:1 로 보낼까, 1:N 으로 보낼까**

| | 1 : 1 개별 맞춤 | 1 : N 고객군 공통 |
|---|---|---|
| 어떻게 | 사람마다 메일을 따로 씁니다 | 고객군마다 메일 1개를 쓰고 이름·회사만 바꿔 넣습니다 |
| 좋은 점 | 그 회사 이야기가 들어가서 답장률이 높습니다 | 빠르고 저렴합니다 |
| 나쁜 점 | 한 통에 1~2분씩 걸립니다 | 뻔한 내용이 됩니다 |
| 언제 | 중요한 고객 몇 명 | 처음 인사 돌릴 때 많은 인원 |

---

### STEP 3. 홈페이지 분석

`[전체 리서치 실행]` 을 누르면, 명함에 적힌 회사 홈페이지를 하나씩 읽어서
**메일에 쓸 만한 사실**을 뽑아냅니다. 예를 들면 "1998년 개점", "지하주차장 3개 층" 같은 것들입니다.

> **홈페이지에서 아무 사실도 못 찾으면, 그 사람에게는 메일을 만들지 않습니다.**
> 근거 없이 쓰면 뻔한 광고가 되기 때문에 일부러 막아둔 것입니다.

`[이 설정으로 만들어지는 프롬프트 보기]` 를 누르면 **AI에게 실제로 보내는 지시문 전체**가 보입니다.
이 지시문이 이 프로그램의 핵심입니다. 마음에 안 들면 이 두 파일을 고치면 됩니다.

- `src/domain.mjs` — 고객군 정의 (어떤 회사에 어떤 이야기를 할지)
- `src/generate.mjs` — 글쓰기 규칙 (말투, 금지 표현, 길이)

---

### STEP 4. 고객군 선택 `HUMAN`

`[고객군 자동 분류]` 를 누르면 명함을 7가지로 나눕니다.

| 고객군 | 어떤 회사 | 무슨 이야기를 하나 |
|---|---|---|
| 리테일·복합몰 | 백화점, 쇼핑몰 | 지하주차장 균열, 영업 중단 없는 점검 |
| 대학·병원 캠퍼스 | 대학교, 의료재단 | 건물마다 점검 시기가 달라 헷갈리는 문제 |
| 오피스·자산관리 | 리츠, 부동산 운용사 | 매각·실사 때 필요한 구조안전 보고서 |
| 방송·통신 특수구조물 | 송신소, 중계소, 기지국 | 사람 안 올리고 드론으로 점검 |
| 시공사·정비사업 | 건설사, 재건축조합 | 철거 후 옆 건물 균열 민원 대비 |
| 제조·물류 | 공장, 물류센터 | 가동 멈추지 않고 점검 |
| 공공·시설관리공단 | 지자체, 공단 | 관리 시설이 많아 일정 놓치는 문제 |

그다음 **보낼 사람을 체크박스로 직접 고르세요.** 고객군 이름 버튼을 누르면 그 그룹이 한 번에 선택됩니다.

> 왜 사람이 고르나요? 분류는 회사 이름만 보고 하는 거라 틀릴 수 있고,
> 무엇보다 **"이 사람에게 지금 연락해도 되는 관계인가"는 담당자만 압니다.**

### STEP 5. 카피 생성

채널(이메일/문자/리멤버 메시지)을 고르고 `[생성]` 을 누릅니다.
한 통에 1~2분 걸립니다. 진행 상황이 화면에 표시됩니다.

### STEP 6. 검토·승인 `HUMAN`

만들어진 메일이 하나씩 나옵니다. **제목과 본문을 직접 고칠 수 있습니다.**

각 메일 위에 초록/빨강 배지가 붙습니다. 자동 검사 결과입니다.

| 배지 | 뜻 |
|---|---|
| 홈페이지 사실 인용 | 그 회사 이야기가 실제로 들어갔는가 |
| 실적 레퍼런스 인용 | 에이톰의 실제 실적을 인용했는가 (없는 실적을 지어내지 않았는가) |
| 법정 해당 여부 단정 안 함 | "반드시 대상입니다" 처럼 단정하지 않았는가 |
| (광고) 표기 | 법에서 요구하는 표시가 있는가 |
| 수신거부 안내 | 거부 방법이 적혀 있는가 |
| 첫 접촉에 견적 요구 없음 | 처음부터 돈 이야기를 꺼내지 않았는가 |

**`[승인]` 을 누른 것만 발송 단계로 넘어갑니다.** 누르지 않으면 절대 나가지 않습니다.

### STEP 7. 발송·추적

- `[큐 적재]` — 보내지 않고 목록에만 올립니다. 연습용입니다.
- `[실제 Gmail 발송]` — 진짜로 보냅니다. 확인 창이 한 번 더 뜹니다.

메일을 실제로 보내려면 아래 준비가 필요합니다.

#### Gmail 앱 비밀번호 만들기

1. https://myaccount.google.com/apppasswords 접속
   (2단계 인증이 켜져 있어야 이 메뉴가 보입니다)
2. 앱 이름에 `proto-rem` 을 입력하고 **생성**
3. 나타나는 **16자리**를 복사 (공백은 무시해도 됩니다)
4. `proto-rem` 폴더에 `.env` 파일을 만들고 아래를 넣습니다

```
GMAIL_USER=보내는주소@gmail.com
GMAIL_APP_PASSWORD=여기에16자리
GMAIL_FROM_NAME=에이톰엔지니어링
DRY_RUN=1
```

5. 터미널에서 Ctrl+C 로 프로그램을 끄고 `npm start` 로 다시 켭니다

> **`DRY_RUN=1` 은 "보내는 척만 하기" 입니다.** 연습이 끝나고 진짜 보낼 때 `0` 으로 바꾸세요.
>
> **주의**: 구글 **계정 비밀번호**나 **2단계 인증 백업 코드**는 여기에 쓸 수 없습니다.
> 반드시 위에서 만든 **앱 비밀번호 16자리**여야 합니다.

#### 자동으로 걸리는 안전장치

| 언제 | 어떻게 되나 |
|---|---|
| 승인 안 한 메일 | 아예 발송 목록에 없습니다 |
| 밤 9시 ~ 아침 8시 | 발송이 거부됩니다 (광고 메일 야간 발송 제한) |
| 같은 사람에게 30일 안에 또 보내려 할 때 | 막힙니다 |
| `.env` 가 없을 때 | 발송 버튼이 아예 눌리지 않습니다 |

> 밤에 **본인에게 테스트**하고 싶으면 `.env` 에 `ALLOW_NIGHT_SEND=1` 을 추가하세요.
> 실제 캠페인을 돌리기 전에는 반드시 지우셔야 합니다.

## 인터넷에 올리기 (Render 배포)

지금까지는 내 컴퓨터에서만 돌았습니다. 다른 사람도 쓰게 하려면 인터넷 서버에 올려야 합니다.
**Render** 는 무료로 시작할 수 있는 서버 서비스입니다.

### 먼저 알아두실 것

인터넷에 올리면 **명함 가져오기 기능은 동작하지 않습니다.**
그 기능은 내 컴퓨터의 크롬을 써야 하는데, 서버에는 크롬이 없기 때문입니다.

| 기능 | 내 컴퓨터 | 인터넷(Render) |
|---|---|---|
| 7단계 화면 | 됨 | 됨 |
| 홈페이지 분석 | 됨 | 됨 |
| 메일 작성 | 됨 | 됨 |
| Gmail 발송 | 됨 | 됨 |
| **리멤버 명함 가져오기** | 됨 | **안 됨** |
| 작업 내용 저장 | 파일로 저장 | **재배포하면 사라짐** (무료 플랜) |

그래서 실제로는 **명함은 내 컴퓨터에서 뽑아 올리고, 나머지는 서버에서** 하는 식으로 씁니다.

> **데이터를 서버에 영구히 두려면** Render 유료 플랜(Starter 이상)으로 올린 뒤
> `render.yaml` 의 `disk:` 세 줄 주석을 풀면 됩니다. 코드는 손댈 필요가 없습니다 —
> `/var/data` 가 붙어 있으면 프로그램이 알아서 그쪽에 저장합니다.
> 화면 왼쪽 아래 **[저장]** 칸이 지금 상태를 **영구 / ⚠ 배포시 초기화** 로 알려 줍니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `npm start` 했는데 `EADDRINUSE` | 이미 켜져 있습니다. `Get-NetTCPConnection -LocalPort 5173 -State Listen` 로 확인 후 종료 |
| 화면이 안 열림 | 터미널 창이 꺼졌는지 확인. `npm start` 다시 실행 |
| 카피 생성이 너무 느림 | 아래 "AI 백엔드" 참고 |
| 명함이 0건으로 나옴 | 스니펫 상자의 `[원본 응답 저장]` 을 눌러 파일을 확인하면 원인을 알 수 있습니다 |

### AI 백엔드 — 왜 느린가

메일을 쓰는 AI는 세 가지 중 하나를 씁니다. 자동으로 골라지지만 `.env` 의 `LLM_BACKEND` 로 지정할 수 있습니다.

| 이름 | 어디서 도나 | 속도 | 비용 |
|---|---|---|---|
| `ollama` | 내 컴퓨터 | **매우 느림 (GPU 없으면)** | 무료 |
| `claude-cli` | Claude Code 통해서 | 보통 (1통 90초) | 구독에 포함 |
| `claude-api` | 인터넷 | 빠름 | 사용한 만큼 |

**실제 측정값** (Snapdragon ARM 노트북 기준)

| 방식 | 1통 쓰는 시간 |
|---|---|
| ollama · exaone3.5:7.8b | 300초 넘음 |
| ollama · exaone3.5:2.4b | 338초 |
| **claude-cli** | **90초** |

이 노트북은 Snapdragon(ARM) CPU 라 Ollama가 그래픽카드를 못 씁니다.
그래서 **기본값을 `claude-cli` 로 두었습니다.** 그래픽카드가 있는 컴퓨터라면
`.env` 에 `LLM_BACKEND=ollama` 한 줄만 넣으면 로컬로 돌아갑니다.

## 만든 사람이 알아야 할 것 (개발자용)

### 폴더 구조

```
proto-rem/
├── src/
│   ├── server.mjs      웹 서버 + 7단계 API
│   ├── domain.mjs      고객군 정의 · 에이톰 실적 목록   ← 여기를 자주 고칩니다
│   ├── generate.mjs    메일 작성 프롬프트 · 검증 규칙   ← 여기도 자주 고칩니다
│   ├── enrich.mjs      홈페이지 읽고 사실 추출
│   ├── normalize.mjs   리멤버 응답 → 명함 스키마 변환
│   ├── llm.mjs         AI 백엔드 선택 (ollama/claude)
│   ├── deliver.mjs     Gmail 발송
│   ├── store.mjs       상태 저장 (data/state.json)
│   └── env.mjs         .env 읽기
├── public/
│   ├── index.html      화면 뼈대 + 디자인
│   ├── app.js          화면 동작
│   └── collect-snippet.js  리멤버 콘솔에 붙여넣는 수집기
├── scripts/
│   ├── login.mjs       전용 프로필 로그인
│   ├── export-cards.mjs 명함 반출 (profile/cdp)
│   └── e2e.mjs         7단계 전체 테스트
└── docs/               설계 문서
```

### 명령어

```powershell
npm start                      # 대시보드 (= python -m py.server)
npm run smoke                  # 7단계 전체 자동 점검 (서버를 먼저 켜 두세요)
npm run login                  # 리멤버 전용 브라우저에 로그인 (한 번만)
npm run export                 # 명함 반출 (전용 프로필)
npm run export -- --via=cdp    # 명함 반출 (이미 켜 둔 크롬에 붙기)
npm run start:node             # 옛 Node 서버 (참고용, 더는 배포에 쓰지 않음)
```

환경변수로 바꿀 수 있는 것들:

```powershell
$env:PORT=8787                 # 화면 주소 (기본 5173)
$env:APP_PASSWORD="비밀번호"     # 넣으면 로그인 화면이 먼저 뜬다
$env:DATA_DIR="D:\safelead"    # 데이터를 둘 폴더 (재배포에도 살아남게)
$env:TEST_REDIRECT_TO="me@x.com"  # 모든 메일을 이 주소로만 (테스트용)
$env:LLM_BACKEND="claude-api"  # 메일을 쓸 AI
```

## 꼭 지켜야 할 것

- **명함은 개인정보입니다.** `data/`, `.env`, `.auth/` 는 GitHub에 올라가지 않도록 막아뒀습니다.
  실수로라도 이 폴더의 내용을 공유하지 마세요.
- **광고 메일은 원칙적으로 사전 동의가 필요합니다** (정보통신망법 제50조).
  (광고) 표기·수신거부 안내·야간 발송 차단은 프로그램이 자동으로 처리하지만,
  **동의를 받는 일 자체는 사람이 해야 합니다.**
  실무에서는 ① 1차로 소량의 업무 안내를 보내고 → ② 회신·동의를 받은 분만
  캠페인 대상으로 올리는 2단계 방식을 권합니다.
- **메일은 승인한 것만 나갑니다.** 자동 발송 기능은 일부러 만들지 않았습니다.
