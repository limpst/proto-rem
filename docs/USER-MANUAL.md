## 1. 이 프로그램이 하는 일

리멤버 명함첩에 연락처가 쌓여 있어도, 막상 영업 메일을 보내려면 막막합니다.
누구에게 보낼지, 뭐라고 쓸지 정하는 데 시간이 다 갑니다.

이 프로그램은 그 과정을 대신합니다.

```
리멤버 명함  →  회사 종류별로 분류  →  그 회사 홈페이지를 읽음
                                              ↓
        보내기  ←  사람이 승인  ←  그 회사에 맞는 메일을 씀
```

**중요한 점 하나**: 이 프로그램은 **똑같은 메일을 여러 명에게 뿌리지 않습니다.**
각 회사 홈페이지를 실제로 읽고, 거기서 찾은 내용을 인용해서 씁니다.

예를 들면 이런 식입니다.

> "○○점이 1998년 개점한 8층 건물이고 지하주차장을 3개 층 운영 중인 것을 확인했습니다.
> 이 정도 규모와 연식이면 정밀안전점검 주기가 도래하는 경우가 많아,
> 한 번 확인해 보시길 권해 드립니다."

## 2. 처음 한 번만 하는 준비

### 2-1. 터미널 여는 법

**터미널**은 컴퓨터에 명령을 글자로 입력하는 검은 창입니다.

1. 키보드 **윈도우 키**를 누릅니다
2. `PowerShell` 이라고 칩니다
3. 나오는 **Windows PowerShell** 을 클릭합니다

파란색 또는 검은색 창이 열리면 성공입니다.

### 2-2. Node.js 가 있는지 확인

터미널에 아래를 치고 Enter:

```powershell
node -v
```

- `v20.11.0` 처럼 **v로 시작하는 숫자**가 나오면 → 있습니다. 2-3으로 가세요.
- `인식할 수 없는 이름` 이라고 나오면 → https://nodejs.org 에서
  **LTS** 라고 적힌 큰 버튼을 눌러 설치하고, 터미널을 껐다 다시 여세요.

### 2-3. 프로그램 내려받기

터미널에 **한 줄씩** 치고 각각 Enter:

```powershell
cd C:\Users\사용자이름
```

```powershell
git clone https://github.com/limpst/proto-rem
```

```powershell
cd proto-rem
```

```powershell
npm install
```

마지막 줄은 1~2분 걸립니다. `added N packages` 같은 글이 나오면 끝난 겁니다.

## 3. 프로그램 켜기

터미널에서 (`proto-rem` 폴더 안에 있는 상태로):

```powershell
npm start
```

이런 글이 나오면 성공입니다.

```
proto-rem 대시보드 → http://localhost:5173
```

> ⚠️ **이 터미널 창을 닫지 마세요.** 닫으면 프로그램이 꺼집니다.
> 프로그램을 쓰는 동안 계속 열어두세요. 끌 때는 `Ctrl` + `C` 를 누릅니다.

이제 **크롬 주소창**에 아래를 칩니다.

```
localhost:5173
```

왼쪽에 1번부터 7번까지 메뉴가 보이면 준비 완료입니다.

## 4. STEP 1 — 명함 가져오기

리멤버에서 명함을 이 프로그램으로 옮깁니다. 방법이 3가지인데 **② 번이 제일 쉽습니다.**

### 방법 ② 콘솔 스니펫 (권장)

**1단계.** 크롬에서 새 탭을 열고 아래 주소로 갑니다. 평소처럼 로그인된 상태면 됩니다.

```
card.rememberapp.co.kr
```

**2단계.** proto-rem 화면(`localhost:5173`)으로 잠깐 돌아와서 **[스니펫 복사]** 를 누릅니다.
"복사했습니다" 라고 뜹니다.

**3단계.** 다시 리멤버 탭으로 가서 키보드 **F12** 를 누릅니다.
화면 오른쪽(또는 아래)에 복잡한 글자가 가득한 창이 열립니다. 놀라지 마세요.

**4단계.** 그 창 위쪽 탭 중에 **Console** 을 클릭합니다.

**5단계.** 아래쪽 빈 곳을 클릭하고 `Ctrl` + `V` 로 붙여넣은 뒤 **Enter**.

> 만약 "붙여넣기를 허용하지 않습니다" 같은 경고가 나오면:
> 그 자리에 `allow pasting` 이라고 **직접 타이핑**하고 Enter → 그다음 다시 붙여넣기

**6단계.** 화면 오른쪽 아래에 작은 검은 상자가 나타납니다.

```
proto-rem 명함 수집
API 3건 · 명함 2건
명함 목록을 아래로 끝까지 스크롤하세요.
[대시보드로 바로 보내기]
[JSON 파일로 저장]
```

**7단계.** 명함 목록을 마우스 휠로 **맨 아래까지 쭉 내립니다.**
내릴수록 상자의 "명함 N건" 숫자가 올라갑니다.

**8단계.** **[대시보드로 바로 보내기]** 를 누릅니다.
"명함 N건을 대시보드로 보냈습니다" 라고 뜨면 끝입니다.

**9단계.** proto-rem 화면으로 돌아와 **[명함 불러오기]** 를 누릅니다.
표에 명함이 나타납니다.

### 방법 ① 전용 브라우저 로그인

명함을 자주 가져오실 거면 이 방법이 편합니다.

1. **[브라우저 열어 로그인]** 클릭 → 새 크롬 창이 열립니다
2. 그 창에서 **직접 로그인**합니다
3. 명함 목록이 보이면 창이 자동으로 닫힙니다
4. 다음부터는 **[전부 가져오기]** 버튼만 누르면 됩니다

> ⚠️ **구글 로그인은 이 창에서 막힙니다.** 구글이 자동화된 브라우저를 차단하기 때문입니다.
> **네이버나 카카오**로 로그인하세요.

### 방법 ③ CDP 접속

크롬을 껐다 켜야 해서 번거롭지만, 완전 자동입니다.

터미널에 아래 두 줄을 순서대로:

```powershell
Get-Process chrome | Stop-Process -Force
```

```powershell
& "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222
```

> 첫 줄은 **크롬을 전부 끕니다.** 열어둔 탭이 다 닫히니 필요한 건 먼저 저장하세요.
> 둘째 줄 맨 앞의 `&` 기호를 빠뜨리면 오류가 납니다.

그다음 **[CDP 로 가져오기]** 를 누릅니다.

### 자동으로 빠지는 명함

| 표시 | 뜻 |
|---|---|
| **자사** | 에이톰엔지니어링 직원 명함입니다. 우리 회사에 광고를 보낼 순 없으니 자동으로 빠집니다 |
| **제외됨** | 명함이 아닌 항목(본인 프로필 등). **[제외]** 버튼으로 직접 뺄 수도 있습니다 |

> 리멤버 API가 명함 목록과 함께 본인 프로필도 같이 보내줍니다.
> 그래서 명함첩에 2건인데 3건으로 보일 수 있습니다. **[제외]** 를 누르면 빠집니다.

## 5. STEP 2 — 누가, 어떻게 보낼지 정하기

**HUMAN** 단계입니다. 사람이 결정하세요.

### 5-1. 보내는 회사

㈜에이톰엔지니어링으로 **고정**입니다. 바꿀 수 없습니다.

### 5-2. 누구 이름으로 보낼까

4개 중 하나를 클릭합니다. 고르는 사람에 따라 **말투와 약속할 수 있는 범위**가 달라집니다.

| 고르면 | 말투 | 이런 약속을 합니다 |
|---|---|---|
| **대표** | 짧고 단정하게 | "제가 직접 검토해 드리겠습니다" |
| **마케팅 담당자** | 친절하고 자세하게 | 자료 제공, 일정 조율 |
| **영업 담당자** | 만난 이야기부터 | 현장 방문, 사전 검토 |
| **기술 담당자** | 기술 근거 위주 | 점검 방법, 소요 일정 설명 |

### 5-3. 1:1 로 보낼까, 1:N 으로 보낼까

| | **1 : 1 개별 맞춤** | **1 : N 고객군 공통** |
|---|---|---|
| 어떻게 | 한 사람당 한 통씩 새로 씁니다 | 고객군마다 한 통 쓰고 이름·회사만 바꿔 넣습니다 |
| 좋은 점 | 그 회사 이야기가 들어가서 답장률이 높습니다 | 빠릅니다 |
| 나쁜 점 | 한 통에 1~2분 걸립니다 | 내용이 일반적입니다 |
| 언제 쓰나 | 중요한 고객 몇 명 | 처음 인사 돌릴 때 여러 명 |

### 5-4. 회사 홈페이지 확보

**[홈페이지 자동 찾기]** 를 누릅니다. 이 순서로 찾습니다.

1. 명함에 홈페이지 주소가 적혀 있으면 그걸 씁니다
2. 없으면 **이메일 주소의 뒷부분**으로 추측합니다
   - `atom@atom-eng.co.kr` → `atom-eng.co.kr` → **접속 성공** → 채택
   - `hong@gmail.com` → gmail 은 회사 주소가 아니므로 건너뜁니다
3. 그래도 없으면 **AI에게 회사 이름으로 물어봅니다**

> ⚠️ **AI가 답한 주소를 그냥 믿지 않습니다.** 실제로 접속해 보고,
> 열리는 주소만 씁니다. 그래서 AI가 없는 주소를 지어내도 문제가 없습니다.

찾지 못하면 표의 홈페이지 칸에 **직접 입력**하시면 됩니다. 입력하고 다른 곳을 클릭하면 저장됩니다.

## 6. STEP 3 — 회사 홈페이지 읽기

**[전체 리서치 실행]** 을 누르면 각 회사 홈페이지를 읽어서 메일에 쓸 사실을 뽑아냅니다.

표의 "리서치 근거" 칸에 이런 게 나옵니다.

```
• 수원점은 1998년 개점한 지상 8층 규모의 복합쇼핑시설이다
• 지하주차장을 3개 층 운영하며 총 1,200면을 제공한다
```

> ⚠️ **근거를 하나도 못 찾은 회사는 메일이 만들어지지 않습니다.**
> 일부러 그렇게 만들었습니다. 근거 없이 쓰면 "저희는 안전진단 전문업체입니다" 같은
> 뻔한 광고가 되고, 그런 메일은 아무도 읽지 않습니다.

### AI에게 뭐라고 시키는지 보기

**[AI 에게 보낼 지시문 미리보기]** 를 누르면, 프로그램이 AI에게 보내는 글 전체가 나옵니다.
"이 회사에 이런 말투로, 이런 실적만 인용해서, 이런 규칙을 지켜서 써라" 하는 내용입니다.

마음에 안 드는 부분이 있으면 이 두 파일을 고치면 됩니다.

- `src/domain.mjs` — 고객군별로 무슨 이야기를 할지
- `src/generate.mjs` — 말투, 금지 표현, 길이

## 7. STEP 4 — 보낼 사람 고르기

**HUMAN** 단계입니다.

**[고객군 자동 분류]** 를 누르면 회사 이름을 보고 7가지로 나눕니다.

| 고객군 | 어떤 회사인가 | 무슨 이야기를 하나 |
|---|---|---|
| 리테일·복합몰 | 백화점, 쇼핑몰, 마트 | 지하주차장 균열, 영업 중단 없이 점검 |
| 대학·병원 캠퍼스 | 대학교, 의료재단 | 건물마다 점검 시기가 달라 헷갈리는 문제 |
| 오피스·자산관리 | 리츠, 부동산 운용사 | 매각·실사 때 필요한 구조안전 보고서 |
| 방송·통신 특수구조물 | 송신소, 중계소, 기지국 | 사람 안 올리고 드론으로 점검 |
| 시공사·정비사업 | 건설사, 재건축조합 | 철거 후 옆 건물 균열 민원 대비 |
| 제조·물류 | 공장, 물류센터 | 가동 멈추지 않고 점검 |
| 공공·시설관리공단 | 지자체, 공단 | 관리 시설이 많아 일정 놓치는 문제 |

그다음 표에서 **체크박스로 보낼 사람을 직접 고릅니다.**
고객군 이름 버튼을 누르면 그 그룹 전체가 한 번에 선택됩니다.

> **왜 사람이 고르나요?**
> 분류는 회사 이름만 보고 하는 거라 틀릴 수 있습니다.
> 그리고 무엇보다, **"이 사람에게 지금 연락해도 되는 사이인가"는 담당자만 압니다.**

## 9. STEP 6 — 읽어보고 승인하기

**HUMAN 단계이고, 가장 중요한 단계입니다.**

만들어진 메일이 하나씩 나옵니다. **제목과 본문을 직접 고칠 수 있습니다.**
글자를 고치고 **[고친 내용만 저장]** 을 누르면 저장됩니다.

### 초록/빨강 배지가 뭔가요

프로그램이 자동으로 검사한 결과입니다.

| 배지 | 무엇을 검사하나 |
|---|---|
| 홈페이지 사실 인용 | 그 회사 이야기가 실제로 들어갔는가 |
| 실적 레퍼런스 인용 | 에이톰의 **진짜 실적**을 인용했는가 (없는 실적을 지어내지 않았는가) |
| 법정 해당 여부 단정 안 함 | "반드시 대상입니다" 처럼 단정하지 않았는가 |
| (광고) 표기 | 법에서 요구하는 표시가 있는가 |
| 수신거부 안내 | 거부하는 방법이 적혀 있는가 |
| 첫 접촉에 견적 요구 없음 | 처음부터 돈 이야기를 꺼내지 않았는가 |

빨간 배지가 있어도 보낼 수는 있습니다. 하지만 **왜 빨간지 확인하고 고치시는 게 좋습니다.**

### 승인 / 반려

| 버튼 | 결과 |
|---|---|
| **승인** | 발송 단계로 넘어갑니다 |
| **반려** | 보내지 않습니다 |
| **고친 내용만 저장** | 글자만 저장. 승인은 안 됩니다 |

> ⚠️ **승인한 메일만 나갑니다.** 자동으로 나가는 일은 없습니다.

## 11. 메일 발송 설정하기

실제로 메일을 보내려면 **한 번만** 설정하면 됩니다.

### 11-1. 앱 비밀번호 만들기

> ⚠️ **구글 계정 비밀번호를 쓰면 안 됩니다.**
> **2단계 인증 백업 코드도 아닙니다.**
> "앱 비밀번호" 라는 **별도의 16자리 비밀번호**를 새로 만들어야 합니다.

1. 크롬에서 https://myaccount.google.com/apppasswords 접속
2. 2단계 인증이 꺼져 있으면 이 메뉴가 안 보입니다. 먼저 켜세요
3. 앱 이름 칸에 `proto-rem` 입력 → **만들기**
4. 노란 상자에 **영어 16글자**가 나옵니다. 이걸 복사합니다 (공백은 무시)

### 11-2. .env 파일 만들기

`proto-rem` 폴더 안에 **`.env`** 라는 이름의 파일을 만듭니다. (앞의 점도 포함)

메모장으로 만드실 때는 저장할 때 **파일 형식을 "모든 파일"** 로 바꾸고
파일 이름에 `.env` 를 그대로 쓰세요.

내용:

```
GMAIL_USER=보내는주소@gmail.com
GMAIL_APP_PASSWORD=여기에16글자
GMAIL_FROM_NAME=에이톰엔지니어링
DRY_RUN=1
```

### 11-3. 프로그램 다시 켜기

터미널에서 `Ctrl` + `C` 를 눌러 끄고, 다시 `npm start`.

왼쪽 아래 "메일" 항목이 **연습모드** 로 바뀌면 성공입니다.

### 11-4. 진짜로 보내기

`DRY_RUN=1` 은 **"보내는 척만 하기"** 입니다. 연습이 끝나면 `0` 으로 바꾸세요.

```
DRY_RUN=0
```

> **첫 발송은 꼭 본인 주소로 테스트하세요.**
> 명함 하나의 이메일을 본인 주소로 바꾸고, 그 한 건만 승인해서 보내보시면
> 실제로 어떻게 도착하는지 확인할 수 있습니다.

## 12. 문제가 생겼을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| `npm start` 했더니 `EADDRINUSE` | 이미 켜져 있습니다 | 다른 터미널 창에서 `Ctrl`+`C` 로 끄고 다시 |
| 화면이 하얗게 비어 있음 | 프로그램이 꺼졌습니다 | 터미널 창 확인, `npm start` 다시 |
| 명함이 0건으로 나옴 | 스크롤을 안 했거나 로그인이 안 됨 | 리멤버에서 명함 목록을 끝까지 스크롤했는지 확인 |
| 메일 만들기가 너무 느림 | AI가 로컬에서 도는 중 | `.env` 에 `LLM_BACKEND=claude-cli` 추가 |
| "홈페이지 근거 부족" 으로 안 만들어짐 | 그 회사 홈페이지를 못 읽음 | STEP 2 에서 홈페이지 주소를 직접 입력 |
| 발송 버튼이 회색 | `.env` 가 없거나 승인한 메일이 없음 | 11장 참고, STEP 6 에서 승인 |
| 밤에 발송이 거부됨 | 야간 발송 제한 | 아침 8시 이후에 하거나, 테스트면 `.env` 에 `ALLOW_NIGHT_SEND=1` |

### 프로그램이 느릴 때

메일 쓰는 AI는 3가지 중 하나로 돌아갑니다.

| 이름 | 어디서 도나 | 한 통 쓰는 시간 |
|---|---|---|
| `ollama` | 내 컴퓨터 | **338초** (그래픽카드 없을 때) |
| `claude-cli` | Claude Code 통해서 | **90초** ← 기본값 |
| `claude-api` | 인터넷 | 빠름 (API 키 필요) |

느리면 `.env` 에 아래를 넣으세요.

```
LLM_BACKEND=claude-cli
```

## 13. 자주 묻는 질문

**Q. 제 명함 데이터가 인터넷으로 나가나요?**

명함 자체는 이 컴퓨터의 `data/proto-rem.db` 파일에만 저장됩니다.
다만 메일을 만들 때 AI에게 이름·회사·직함이 전달됩니다.
이것도 밖으로 안 내보내려면 `.env` 에 `LLM_BACKEND=ollama` 를 넣으면 되지만,
그래픽카드가 없는 컴퓨터에서는 한 통에 5분 넘게 걸립니다.

**Q. 실수로 메일이 나갈 일은 없나요?**

없습니다. 3중으로 막혀 있습니다.
① 승인한 것만 목록에 오릅니다 ② 발송 버튼을 따로 눌러야 합니다
③ 확인 창이 한 번 더 뜹니다. 그리고 `DRY_RUN=1` 이면 아무것도 나가지 않습니다.

**Q. 광고 메일 보내도 법적으로 괜찮나요?**

**원칙적으로는 미리 동의를 받아야 합니다** (정보통신망법 제50조).
명함을 교환했다는 것만으로 광고 수신에 동의한 것으로 보기는 어렵습니다.

이 프로그램은 (광고) 표시, 수신거부 안내, 야간 발송 차단을 자동으로 처리하지만,
**동의를 받는 일 자체는 사람이 해야 합니다.**

실무에서는 이렇게 하시길 권합니다.
① 처음에는 소량으로 업무 안내 성격의 메일을 보내고
② 회신하거나 동의한 분만 캠페인 대상으로 올립니다.

**Q. 작업하던 게 사라졌어요.**

`data/proto-rem.db` 파일에 저장되므로 프로그램을 껐다 켜도 남아 있습니다.
**[전체 초기화]** 버튼을 누르면 지워지니 주의하세요.

**Q. 인터넷에 올려서 다른 사람도 쓰게 할 수 있나요?**

가능합니다. [README의 Render 배포](../README.md#배포) 부분을 보세요.
다만 **명함 가져오기 기능은 인터넷 서버에서 동작하지 않습니다.**
그 기능은 내 컴퓨터의 크롬을 써야 하기 때문입니다.

**Q. 문자(SMS)도 보낼 수 있나요?**

문자 **문안을 만드는 것**은 됩니다 (STEP 5에서 채널을 문자로 선택).
다만 **실제 전송은 아직 연결되지 않았습니다.** 문자를 보내려면
알리고·솔라피 같은 문자 발송 업체와 계약하고 그 API를 연결해야 합니다.
