# 04. 로드맵

**목표: 7단계가 한 화면에서 끝까지 흐르는 것을 눈으로 확인**

- [x] 7단계 파이프라인 서버 + 대시보드 (`npm start`)
- [x] 세그먼트 7종 + 에이톰 실적 레퍼런스 매핑
- [x] target 홈페이지 크롤 → 근거 추출
- [x] source(자사) 홈페이지 프로파일링
- [x] Claude 기반 1:1 카피 생성 (API 키 없이 Claude Code CLI 경유)
- [x] 컴플라이언스 자동 삽입 + 검증 6항목
- [x] HITL 게이트 2곳 (대상 선택 / 문안 승인)
- [ ] 리멤버 실데이터 반출 (CDP 접속 — Chrome 디버깅 포트 실행 필요)

## Phase 1 — 실사용 파일럿 (에이톰 내부)
**목표: 실제 명함으로 첫 미팅 1건 만들기**

- 리멤버 반출 안정화 + 팀 명함첩 지원
- 홈페이지 미보유 회사 처리 (검색 기반 URL 탐색)
- 발송 채널 1개 실연동 (메일 우선 — 이력·수신거부 관리가 가장 명확)
- `consent_status` 관리: 1차 개별 접촉 → 동의 확보 → 캠페인 대상 승격
- 응답 추적 (회신 감지 → `REPLIED`)
- **성공 기준**: 발송 50건 → 유효 응답 3건 이상

## Phase 2 — 법정 점검 시계 (핵심 차별화)
**목표: "지금 연락할 이유"를 시스템이 계산**

- 건축물 신호(준공연도·용도·연면적) → 법정 점검 도래 시점 추정 룰 엔진
- 공개 데이터 연계(건축물대장 등) 검토
- 도래 임박 순 자동 우선순위 + 알림
- 세그먼트를 사람이 만드는 **세그먼트 빌더 UI** (조건 조합 저장)

## Phase 3 — SaaS 전환
**목표: 에이톰 외 사업자도 쓰게 만들기**

- PostgreSQL + RLS 멀티테넌시 정식 적용
- 테넌트별 온보딩: 자사 홈페이지 URL만 넣으면 서비스·레퍼런스 자동 프로파일링 → 세그먼트 초안 생성
- 사용량 계량 → 요금제 (Free / Pro / Team)
- 팀 협업: 담당자 배정, 중복 접촉 방지(같은 회사에 두 영업사원이 동시 접촉 차단)
- 성과 대시보드: 세그먼트별 응답률 → 프롬프트 자동 개선 루프

## 우선순위 판단 기준
매 단계에서 **"이게 없으면 매출이 안 나는가?"** 하나로 판단한다.
지금 이 기준을 통과하는 미완료 항목은 **리멤버 실데이터 반출**과 **메일 실연동** 둘뿐이다.
